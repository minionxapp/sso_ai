pembuatan aplikasi SSO (single sign on)

Fitur yang diharapkan:
- SSO (Single Sign On)
- OAuth 2.0 / OpenID Connect
- Dashboard manajemen pengguna
- Dashboard manajemen aplikasi
- Laporan log audit
- Integrasi pihak ketiga (SaaS eksternal)
- Otomasi Onboarding/Offboarding
- HR Information System (HRIS)
- Penetration Testing (Pen Test)
- Vulnerability Assessment (VA)
- Identity Provider
- Manajemen pengguna (CRUD)
- Manajemen aplikasi (CRUD)
- Manajemen role dan permission
- Manajemen log audit
- integrasi aplikasi dengan sso
- otomasi onboarding
- otomasi offboarding
- enable/disable user
- reset password user
- update role user
- user profile
- security setting
- multi tenant
- self service password reset

aplikasi terbagi antara backend dan frontend

backend menggunakan framework nodejs dengan struktur project seperti pada https://github.com/minionxapp/rest-api

frontend menggunakan framework vue3
